# Закрывающий тег

Одностраничный сайт с адаптивной вёрсткой, анимациями и модальным окном.

🔗 **GitHub Pages:** [посмотреть проект](https://annyamark.github.io/zakrivayuschiy-teg-f/)

## 📖 Описание

«Закрывающий тег» — это лендинг, стилизованный под личный блог или дневник воспоминаний.  
Страница содержит:
- фиксированный градиентный фон с повторяющейся сеткой,
- резиновую шапку с адаптивными отступами и шрифтами,
- 8 карточек с текстом, изображениями и анимированными иконками лайка,
- модальное окно с кнопкой «Сохранить на память».

Все размеры, отступы и шрифты плавно меняются с помощью `clamp()` без использования медиазапросов (за исключением точечной корректировки на узких экранах).

## 🛠️ Технологии

- HTML5, CSS3
- Flexbox, Grid
- Адаптивная и резиновая вёрстка
- CSS-переменные (кастомные свойства)
- Функция `clamp()` для плавного масштабирования
- Псевдоэлементы `::before`, `::backdrop`
- `repeating-linear-gradient` и `linear-gradient`
- `<dialog>` для модального окна
- CSS-анимации (`transition`, `@keyframes`, `transform`)
- SVG-спрайты и инлайновые SVG
- JavaScript (открытие модального окна, переключение лайков)
